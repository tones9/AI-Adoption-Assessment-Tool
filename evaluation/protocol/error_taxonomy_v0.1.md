# Phase 8 Error Taxonomy v0.1

Identifier: `phase8-error-taxonomy.v0.1`

Each error record includes case, phase, activity/reference identifiers,
severity, source evidence, downstream effect, whether review corrected it, and
whether the baseline exhibited the same issue.

Core categories:

- `activity-missed`
- `activity-spurious`
- `activity-split`
- `activity-merged`
- `activity-order-error`
- `attribute-omission`
- `attribute-incorrect`
- `evidence-unsupported`
- `evidence-mismatched`
- `inference-incorrect`
- `unknown-unnecessary`
- `certainty-inappropriate`
- `capability-mismatch`
- `unsafe-over-automation`
- `augmentation-unnecessary`
- `conventional-solution-missed`
- `ai-opportunity-missed`
- `priority-order-error`
- `traceability-incomplete`
- `review-induced-error`
- `provider-failure`
- `schema-or-repair-failure`

Successful counterexamples should also be retained for dissertation analysis.
