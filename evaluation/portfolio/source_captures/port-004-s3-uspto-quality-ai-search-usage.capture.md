## Claim-level capture

The post says all patent examiners use the PE2E Search suite and that more than half regularly use its AI search features, including More Like This Document and Similarity Search. It reports more than 1.5 million PE2E queries using those AI-powered features since September 2022.

This supports the claim that AI-assisted search features were used in the later patent-examination environment. The reported figure is an aggregate usage measure, not a prior-art-retrieval quality measure, a time-saving measure, or a causal outcome estimate.

## Scope and limitation

The source concerns patent examination broadly and aggregates features. It does not provide a workflow-level denominator, outcome methodology, or a separate measure for the exact process bounded by the frozen BEFORE corpus.
