## Claim-level capture

The USPTO states that utility patent examiners began conducting prior-art searches with Similarity Search (SimSearch) in September 2022. It describes SimSearch as an AI-assisted PE2E Search feature that uses application text to generate a query and returns ranked similar documents.

The source says the feature augments other search tools rather than replacing them, and that examiners retain discretion over whether to apply search results. It also describes examiner refinement of the search by emphasising selected application information.

## Scope and limitation

This is the direct official source for the later intervention in the same broad examiner prior-art-search workflow. It does not demonstrate that every examiner used the feature, that it improved search quality in a measured way, or that the specific frozen manual steps were replaced.
